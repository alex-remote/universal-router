# 合约库

## 概述

本目录包含可复用的 Solidity 库，为 Universal Router 各合约提供共享功能。这些库负责命令定义、常量、锁机制以及输入数量计算。

## 关键文件

- `Commands.sol` - 路由器操作的命令类型定义与常量
- `Constants.sol` - 协议级常量（地址、魔数值、标志位）
- `Locker.sol` - 重入锁状态管理库
- `MaxInputAmount.sol` - 用于计算兑换中最大输入数量的工具

## 用途

库提供：
- **命令系统**：用于路由操作的标准化命令字节码
- **共享常量**：协议地址与配置值
- **状态管理**：面向复杂交易流程的线程安全锁
- **数学工具**：兑换输入数量的安全计算
