# 部署地址

## 概述

本目录包含 JSON 文件，记录每个受支持网络上已部署的 Universal Router 合约地址。每个文件将合约名称映射到其在特定区块链上的部署地址。

## 网络

**主网：**
- `mainnet.json` - Ethereum 主网
- `arbitrum.json` - Arbitrum One
- `optimism.json` - Optimism
- `polygon.json` - Polygon PoS
- `base.json` - Base
- `avalanche.json` - Avalanche C-Chain
- `bsc.json` - BNB Smart Chain
- `celo.json` - Celo
- `blast.json` - Blast
